# Prompts

Five prompts for the build. Replace bracketed fields. Do not add non-page deliverables.

## 1. Reference board prompt

```text
生成一张用于 3D 建模的 [产品] 多视角正交参考板。
画面包含同一产品的正面、背面、左侧、右侧、3/4 视角；
严格同比例、同材质、同配色、同结构；
工业设计棚拍渲染，纯白或浅灰背景；
无文字、无水印、无 Logo、无场景道具、无人物；
柔和均匀布光，高细节，边缘清晰；
16:9 或 4:3，高分辨率。

负面：不同款式混排、透视不一致、比例变化、变形、多余部件、文字、水印、复杂背景、过曝、运动模糊。
```

## 2. Part extraction prompt

```text
你是工业产品结构编辑。根据以下产品资料，拆出 8–15 个可独立展示的结构模块。

输出：
- id（kebab-case）
- 中文名 / 英文名
- 分类（frame / power / camera / arm / propulsion / sensor / avionics / comms）
- 60–100 字说明
- 4–5 条参数
- 2–3 个关联模块
- 建议的 3D 锚点
- 建议的拆解方向

规则：
- 模块必须能独立选中和分离；
- 说明写“结构角色 + 与相邻模块的关系”；
- 不编造官方参数；
- 内部结构无法确认时标“概念/示意”。

产品资料：
[粘贴官方参数、拆解图、参考图说明]
```

## 3. Procedural model prompt

```text
为网页实时展示制作 [产品] 的程序化 3D 模型。

格式：Three.js 代码生成，不使用外部 GLB/GLTF。
坐标：Y-up，单位统一，原点在产品中心。
分件：按 [id 列表] 拆成独立 group。
几何：圆角盒、圆柱、挤出、旋转体、薄片扭转；硬表面边缘倒角。
材质：PBR；[主色金属]、[深色塑料]、[青色镜片]、[暖金触点]、[黑色橡胶]。
细节：接缝、关节、镜头环、散热口、触点、天线；不要随机堆细节。
不要：骨骼、动画、相机、灯光、地面、背景、外部贴图。
额外：每个模块给一个 3D 锚点和一个拆解方向。
```

## 4. Three.js build prompt

```text
你是一名资深 Three.js 产品可视化工程师。请实现一个单页 3D 产品结构拆解页。

【产品】[名称/型号/一句话角色]
【模块】[id 列表]
【数据】读取 parts 表：id、name、en、category、description、specs、related、anchor3d、explode3d。
【场景】3/4 前视；深色航空 HUD；地面网格、接触阴影、轻雾；金属/塑料/玻璃 PBR。
【交互】拖拽旋转、滚轮缩放；点击模型/标签/清单选中；home + offset 缓动拆解；全部拆解/重组；自动旋转；视角复位；进度 00/N。
【标签】3D 锚点投影到屏幕；HTML 标签 + SVG 连线；桌面全量、移动端只留当前。
【UI】顶部状态、左侧清单、中间模型、右侧详情、底部公开参数、加载层、操作引导。
【响应式】>1160 三栏；760–1160 抽屉；<760 单栏；触屏旋转/双指缩放。
【性能】pixelRatio ≤ 2；重复件复用几何/材质；无控制台错误；单文件可交付。
【禁止】外部模型/贴图/字体；假参数；手机全量标签；一张图假装 360°。
【验收】1576/1366/1024/390；标注不重叠；抽屉可开合；单文件可双击打开。
```

## 5. QA prompt

```text
请逐项验收页面，输出 PASS/FAIL 和证据：

1. 控制台无错误
2. 无外部模型/贴图/字体依赖
3. 1576/1366/1024/390 四个尺寸正常
4. 8–15 个模块都能单独选中
5. 单件拆解/全部拆解/重组正常
6. 桌面标注不重叠
7. 手机只显示当前标注
8. 手机抽屉可开可关
9. 触屏旋转/缩放正常
10. 参数来源与非官方结构声明一致
11. 单文件可双击打开
12. 无横向滚动
```
